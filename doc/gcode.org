#+TITLE: Supported GCode commands

+ *G0 X<x> Z<z> C<c> F<f>* - Rapid move
  All coordinates optional

  *F* is feedrate, in millimeters per second

+ *G1 X<x> Z<z> C<c> F<f>* - Linear move
  All coordinates optional

  *F* is feedrate, in millimeters per second

  G0 and G1 are synonyms for now

+ *G4 <dur>* - Dwell (sleep)

+ *G28 [F<speed>]* - Home

  *F* is optional feedrate, in millimeters per second. Defaults to 120

+ *M0* - Stop

+ *M17* - Enable all steppers

+ *M18* - Disable all steppers

+ *M114* - Get current position

  Prints current position to debug console

+ *M226* - Pause

  Pause until the "Resume" button is pressed

* Standard preamble

#+begin_src gcode
M0
M17
G28
#+end_src

* Standard postamble

#+begin_src gcode
M18
#+end_src
